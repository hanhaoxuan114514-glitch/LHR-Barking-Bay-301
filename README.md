打开游戏，你会看到一块希思罗机场的航班信息屏。屏上的每一班航班都是一个独立的小游戏，有各自的故事和玩法，挑一班登机就能开始玩。登录后，你的通关成绩会上实时排行榜，收集成就也会保存到账号，换设备仍可查看。

<br>

## 航班列表

### LHR301 · ZRH快跑

横版跑酷。今晚有架 A380 要从 301 机坪起飞，可 ZRH 被妈妈关在了 301 室。
你要带着他穿过走廊、小区和一场肖申克式的雨夜，翻过机场围栏，全程 2000 米，身后的老妈一路紧追，还会甩出拖鞋。

路上捡到的相机和镜头能帮你甩开她一点；看到金色的 Z9 就吃掉，三秒内谁也拦不住你。

- 电脑：`空格` 或 `↑` 跳，空中再按一次可以二段跳；`↓` 滑铲
- 手机：点屏幕右边跳，点左边滑铲

### LHR302 · T2 夜行

3D 俯视角潜行。STEVEN 第一次来伦敦，来接机的姐姐 ZRH 被 security 赶出了 T2 停车楼顶层，她的相机包还落在里面。
你扮演 STEVEN，从航站楼出口溜上楼顶，在车辆和立柱之间穿行，找到相机包，再避开随机巡逻的 security，赶到左上角的车辆入口坡道和她会合。

红色扇形是 security 的视线，车和柱子能挡住；跑步有脚步声，进出的车被挡住会按喇叭；易拉罐扔出去能把人引开。每次出发前会播放 galgame 式的开场剧情（可以一键跳过），再挑一件装备：荧光背心、软底跑鞋或者一袋易拉罐。角色都是平滑的方块人。

- 电脑：`WASD` / 方向键移动，`Shift` 冲刺，`E` / `空格` 扔易拉罐，`M` 俯瞰地图
- 手机：左半屏按住拖动移动（推到底自动冲刺），右下角冲刺 / 扔罐，右上角俯瞰地图

## 成就

主菜单、游戏结算页，以及《T2 夜行》的标题页可以打开「🏆 成就」。

- **Z9 收藏家**：在《ZRH快跑》中单次通关，并收齐本局随机生成的全部尼康 Z9。本局没有出现 Z9 时不解锁；游戏中和结算页会显示收集数量。
- **行李牌收藏家**：在《T2 夜行》中单次通关，并收齐本局的 3 张行李牌。

成就跟随现有账号，登录同一个账号即可在其他设备查看。游客达成后可以登录领取；同步失败时，在当前浏览器标签页保留待保存记录，联网、重新登录或打开成就面板后重试。跨关卡跳转和刷新不会丢失待保存记录，关闭标签页前请完成同步。

## 关于

`index.html` 是主界面和《ZRH快跑》（纯 HTML + Canvas 手绘），`lhr302.html` 是《T2 夜行》（three.js 3D），电脑和手机都适配。登录和排行榜由 Supabase 提供：用邮箱和密码注册登录；通关成绩会实时出现在主界面的排行榜上。

成就的判定、账号同步和面板共用 `achievements.js` / `achievements.css`。两项解锁时间分别保存在 Supabase Auth 的 `user_metadata.lhr_achievement_z9_collector` 和 `user_metadata.lhr_achievement_tag_collector`，通过现有账号接口更新，不需要新增数据库表或迁移。每次同步只提交对应成就字段，保留昵称等资料；请求使用取得时的账号令牌，避免切换账号期间串号。这些是玩家可编辑的个人成就记录，不作为排行榜成绩或奖励权限的依据。

开发验证：`node --test tests/achievements.test.cjs`。浏览器测试为 `tests/browser-achievements.cjs`，需要 Playwright 和 Chrome，以及运行在 `http://127.0.0.1:8765` 的本地静态服务器（可通过 `GAME_TEST_URL` 改地址）。浏览器测试拦截账号及排行榜请求，不写入真实玩家数据。
