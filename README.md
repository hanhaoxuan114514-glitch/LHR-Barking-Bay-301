## 第一章 · ZRH快跑

从家门口一路跑到机坪，全程 2000 米。你会穿过走廊、小区、一场肖申克式的雨夜，最后翻过机场围栏。
身后的老妈一直在追，偶尔还会甩出一只拖鞋。

路上捡到的相机和镜头能帮你甩开她一点；如果看到金色的 Z9，那就是「尼康 Z9 是对的」——三秒内谁也拦不住你。

**怎么玩**

- 电脑：`空格` 或 `↑` 跳，空中再按一次可以二段跳；`↓` 滑铲
- 手机：点屏幕右边跳，点左边滑铲

跑到终点会根据用时和挨了几只拖鞋给你一个称号。零失误的，才配叫「传奇拍机佬」。
