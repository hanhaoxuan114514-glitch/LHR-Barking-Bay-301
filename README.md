打开游戏，你会看到一块希思罗机场的航班信息屏。屏上的每一班航班都是一个独立的小游戏，有各自的故事和玩法，挑一班登机就能开始玩。登录后，你的通关成绩还会上实时排行榜。

<br>

## 航班列表

### LHR301 · ZRH快跑

横版跑酷。今晚有架 A380 要从 301 机坪起飞，可 ZRH 被妈妈关在了 301 室。
你要带着他穿过走廊、小区和一场肖申克式的雨夜，翻过机场围栏，全程 2000 米，身后的老妈一路紧追，还会甩出拖鞋。

路上捡到的相机和镜头能帮你甩开她一点；看到金色的 Z9 就吃掉，三秒内谁也拦不住你。

- 电脑：`空格` 或 `↑` 跳，空中再按一次可以二段跳；`↓` 滑铲
- 手机：点屏幕右边跳，点左边滑铲

### LHR302 · T3 夜行

3D 俯视角潜行。伦敦的第一晚，来接机的学姐苏芮被 security 赶出了 T3 停车楼顶层，她的相机包还落在里面。
你要从航站楼出口溜上楼顶，在车辆和立柱之间穿行，找到相机包，再避开随机巡逻的 security，赶到左上角的车辆入口坡道和她会合。

红色扇形是 security 的视线，车和柱子能挡住；跑步有脚步声，进出的车被挡住会按喇叭；易拉罐扔出去能把人引开。开局前还能挑一件装备：荧光背心、软底跑鞋或者一袋易拉罐。剧情是 galgame 式的对话，角色都是平滑的方块人。

- 电脑：`WASD` / 方向键移动，`Shift` 冲刺，`E` / `空格` 扔易拉罐，`M` 俯瞰地图
- 手机：左边拖动移动，右下角冲刺 / 扔罐

## 关于

`index.html` 是主界面和《ZRH快跑》（纯 HTML + Canvas 手绘），`lhr302.html` 是《T3 夜行》（three.js 3D），电脑和手机都适配。登录和排行榜由 Supabase 提供：用邮箱和密码注册登录；通关成绩会实时出现在主界面的排行榜上。
